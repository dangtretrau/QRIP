# tool-ddos-get-http-proxy
LƯU Ý MÁY PHẢI CÓ SẴN NODE JS !!!
ở đây các og chạy hai file windows và linux trước để cài module cho tool nhé og nào dùng windows thì chạy admin file windows.bat còn og nào dùng linux chạy file linux.sh nhé.
sau khi cài các og có thể chạy tool như bình thường | lệnh: node tentool.js (ở chỗ tentool các og đổi tên thành tool muốn dùng nhé!).
các og chưa có proxy http thì chạy file proxy.js nhé nó sẽ lấy cho các og list proxy http để sử dụng cho các tool. 
các og chưa biết cách dùng thì cứ node tenfile.js ra rồi nó sẽ có hướng dẫn nhé.
